# Proyecto Individual

Un juego interactivo de adivinanzas desarrollado con HTML, CSS y JavaScript.

## Descripción

Este proyecto consiste en un juego donde el usuario debe adivinar un número secreto entre 1 y 10. La interfaz es amigable y cuenta con un diseño moderno que incluye una imagen temática y botones interactivos.

## Características

- Juego de adivinanzas de números
- Interfaz responsive
- Botón para reiniciar el juego
- Enlace a un juego adicional: "Amigo Secreto"
- Diseño atractivo con fuentes personalizadas de Google Fonts
